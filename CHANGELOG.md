# Changelog

## 0.1.0-beta.0

Initial beta, pending publication.

- Transactional email enqueueing through a Convex component and Cloudflare Email Service.
- Status queries, cancellation, bounded rate-limit retries, and explicit handling of uncertain delivery.
- Enqueue deduplication, retention cleanup, and test-mode sending.
- GitHub Actions checks and protected npm release workflow.

Live Cloudflare delivery has not been verified as part of this release preparation.
